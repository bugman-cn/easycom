# easycom

easycom 是一款 Windows 桌面串口调试工具，基于 PySide6 和 pyserial。可以用它查看设备启动日志、收发十六进制数据，或在终端模式下与设备命令行交互。当前版本为 **V1.0**。

## 快速开始

发行包适用于 Windows 10（1809 及以上）和 Windows 11 x64。解压完整 ZIP 后运行 EXE。若提示缺少 `MSVCP140.dll` 或 `VCRUNTIME140.dll`，或已有运行库版本过旧，请安装或更新微软的 x64 运行库，再启动 easycom。[微软官方 Visual C++ v14 x64 运行库](https://aka.ms/vc14/vc_redist.x64.exe)

从源码运行时，先在 Windows 上安装 Python，并确保能在 PowerShell 中运行 `python.exe`。本项目已在 Python 3.12.6 环境下运行。

在项目根目录双击 `run.bat`，也可以从 PowerShell 启动。

```powershell
.\run.ps1
```

首次启动时，脚本会创建 `.venv` 并安装依赖。之后启动会复用该环境。

## 第一次收发

1. 连接串口设备，在窗口顶部选择串口号和设备使用的波特率。点击 `▼` 可设置数据位、停止位和校验位，然后点击 **打开串口**。
2. 在下方发送区输入文本并点击 **发送**。要发送原始字节，先打开**发送区**的 `0x` 按钮。例如输入 `48 69` 并关闭追加换行，实际发送的就是 `0x48 0x69` 两个字节。
3. 在上方接收区查看设备返回的数据。**接收区**的 `0x` 按钮独立控制后续接收数据的显示格式。需要查看每行到达的时间时，打开时钟按钮。

## 常用功能

| 场景 | 操作 |
| --- | --- |
| 排查设备日志 | 在普通接收模式按 `Ctrl+F` 搜索，支持正则、区分大小写和全词匹配。可在设置中为关键字配置高亮颜色。 |
| 与设备命令行交互 | 点击接收区的终端按钮，直接在终端输入。终端模式可解释 ANSI 颜色和光标控制序列。 |
| 重复发送指令 | 从发送历史调出指令，或将常用指令存入扩展命令面板。发送区支持按设定间隔定时发送，并可选择追加 CR、LF 或 CRLF。 |
| 保存调试记录 | 点击接收区的保存按钮导出数据，或在 **设置 → 自动保存日志** 中配置自动保存。 |

## 配置与日志

源码运行时，配置、历史记录和扩展命令保存在项目根目录的 `auto-gen/` 中。运行打包版时，该目录位于 EXE 旁。串口日志默认写入 `auto-gen/uart-log/`，可在设置中更改。使用 `clean.bat` 会删除整个 `auto-gen/`，请先备份需要保留的命令和日志。

## 在线升级

在 **关于 → 检查更新** 查看 GitHub 最新正式版和发布说明。较长的发布说明可在窗口内滚动阅读。通常从公开 Release 页面读取信息，手动重新检查可立即刷新。打包版可以点击 **下载更新**，校验通过后关闭串口、停止定时发送，再点击 **更新并重启**。请先将整个发行包解压到自己有写入权限的目录，并保留程序名 `easycom.exe`。升级会保留同级的 `auto-gen/`、自定义日志和快捷方式。

如果升级中断，关闭所有 easycom 窗口，双击安装目录下的 `.easycom-update/recover.exe` 恢复，再打开程序。详情记录在同目录的 `update.log`。源码运行时可查询版本，使用 Git 获取代码更新。此前分发的旧版需要手动换到含更新入口的版本一次。

## 打包 Windows 发行版

完成首次启动后，在项目根目录运行发布脚本。

```powershell
.\scripts\release.ps1
```

在 x64 环境下，直接按回车即可生成目录版 `dist/easycom-v1.0-win64.zip`。需要单文件版时输入 `y`，生成的 ZIP 带有 `-onefile` 后缀。

发布时在 GitHub 创建与 `config/version.py` 中版本对应的正式 Release，例如 `v1.0`。将生成的目录版 ZIP 按原名上传为附件。下次发布 V1.1 时，已安装的 V1.0 即可在应用内检查并升级。

项目结构和构建选项分别见[框架说明](doc/框架说明.md)和[脚本说明](scripts/README.md)。
